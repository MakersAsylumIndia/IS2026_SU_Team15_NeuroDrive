# CAD RENDER

- 3D print the ENCLOSURE STEP file from the 3d_prints folder
- 3D print the MOTOR MOUNTS STEP files from the 3d_prints folder (two each for left and right)
- Laser cut the CHASSIS base from the laser_cut folder (Acrylic, 3mm or 5mm)
- Use 8mm magnets to attach ENCLOSURE to CHASSIS
